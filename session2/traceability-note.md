Context

This change is needed to document and track project changes in Session 2. It helps ensure that every change can be connected to its issue, branch, pull request, review, and merge result.

Expected result

A traceability note template will be created in `session2/traceability-note.md` to record important information about project changes.

Acceptance criteria

- [ ] File `session2/traceability-note.md` exists.
- [ ] The file contains a field for the issue number.
- [ ] The file contains a field for the branch name.
- [ ] The file contains a field for the pull request.
- [ ] The file contains reviewer and review evidence.
- [ ] The file contains the merge result.
- [ ] The file contains affected files and verification details.

Out of scope

This change does not include creating a complete configuration audit report or changing the existing project functionality.
